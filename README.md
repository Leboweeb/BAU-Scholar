# BAU Scholar

Custom web app for my internship from 2024-2025. This project was one of my best internship experiences and I'm glad I had the opportunity to better my university directly.

In this internship I was tasked with making an end-to-end platform that:
- Aggregates research and tags it.
- Has a DM feature that allows for researchers to chat and form groups. ( This made me learn debouncing, redis, memcached, and websockets. It was the single hardest feature and almost made me give up)
- Generate CVs and other menial forms for researchers in my university.
- Recommend research based on shared tags.

Tech Stack:
- Django/DRF
- HTMX/Javascript
- MySQL DB
- Redis/Memcached
- Docker
